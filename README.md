# Tasty Tok — PWA starter

Это первый рабочий прототип Tasty Tok в формате PWA.

## Что уже работает
- адаптивная главная страница для телефона и компьютера;
- поиск по рецептам;
- категории и фильтры;
- карточки рецептов и подробная страница;
- список ингредиентов с чекбоксами;
- пошаговый режим приготовления;
- избранное и пользовательские рецепты (сохраняются в браузере);
- базовая установка на главный экран и service worker.

## Как запустить
Для проверки локально откройте папку через любой локальный сервер (например, Live Server в VS Code).
Для GitHub Pages загрузите все файлы из архива в корень репозитория и включите Pages в Settings → Pages.

PWA-функции (установка и service worker) работают через HTTPS или localhost. На GitHub Pages HTTPS включён автоматически.

## Важно
Сейчас это стартовая версия с демонстрационными рецептами. Фотографии рецептов загружаются из Unsplash при наличии интернета. Данные избранного и добавленные рецепты хранятся локально в браузере и пока не синхронизируются между устройствами.
