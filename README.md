# Tasty Tok — PWA prototype v0.2

Обновлённый розово-пастельный интерфейс по референсу Tasty Tok. Добавлены иллюстрации маскота Баксика (в образе повара), более мягкие карточки, блок-подсказка от Баксика и обновлённые состояния избранного/режима готовки.

## Что работает
- адаптивная главная для телефона и компьютера;
- поиск по рецептам, категории и фильтры;
- карточки и подробные страницы рецептов;
- отметки ингредиентов;
- пошаговый режим приготовления;
- избранное и добавление собственных рецептов;
- базовая установка PWA и service worker;
- локальное сохранение пользовательских данных в браузере.

## Публикация на GitHub Pages
Загрузите содержимое этой папки в корень репозитория `tasty-tok` с заменой старых файлов. Не загружайте саму папку `tasty_tok_pwa` внутрь репозитория: `index.html` должен лежать в корне. После Commit changes дождитесь обновления GitHub Pages.

## Важно
Избранное и добавленные рецепты пока хранятся только в текущем браузере/устройстве. Фотографии блюд подгружаются из Unsplash и требуют интернета. Для общей базы и синхронизации между устройствами позже понадобится backend.
